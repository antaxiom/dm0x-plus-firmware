# Easter egg

Source: https://toseven.miraheze.org/wiki/Easter_egg

'''Warning: The following will void warranty if done without authorisation. If you're going to do it anyway, don't be a dick and try to claim warranty if you blow a controller or break something.'''

To access the advanced settings on locked motors, while in the main settings menu, scroll to Unit. Then press and hold the up and down buttons together for 10 seconds. If this doesn't work, try holding the “I” and Power buttons together for 10 seconds.
